Thesis title
Development of a Web-Based Formula 1 Telemetry Analysis and Visualization Platform
Author name
Ivanov Aleksandr
General description
This thesis details a web-based application for analyzing Formula 1 telemetry. It focuses on processing, aligning, and visualizing high-frequency time-series data. The core logic uses spatial interpolation to sync asynchronous data points to a common distance axis, enabling precise driver comparisons. The project includes a robust backend for data ingestion and a performant frontend for rendering large datasets, with proven algorithmic accuracy and rendering speed.
Work and schedule
Work to be done:

· Conduct a detailed analysis of the requirements for processing and visualizing large volumes of motorsport time-series data.

· Design a data ingestion pipeline to fetch, parse, and normalize raw telemetry datasets (e.g., speed, throttle, braking, gear, and spatial coordinates) from the OpenF1 API, and implement a storage strategy using a PostgreSQL database to cache processed data and optimize retrieval times.

· Implement complex business logic algorithms, including data smoothing (noise reduction), linear or cubic spline interpolation to align independent data sets by track distance, and calculating time deltas (Delta Time) at specific micro-sectors.

· Design and implement a responsive, highly performant web-based user interface capable of rendering charts with tens of thousands of data points without browser degradation over time.

· Develop backend services using modern technologies (e.g., Node.js/TypeScript) to handle data processing efficiently.
